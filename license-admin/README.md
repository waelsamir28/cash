# مجلد إدارة التراخيص (خاص بك فقط)

هذا المجلد **لا يدخل** ضمن البرنامج المثبت ولا يُنسخ إلى ملف EXE.

## أولاً: إنشاء مفاتيحك (مرة واحدة فقط)

```bash
node license-admin/keygen.mjs
```

- ستُطلب منك **كلمة سر** تختارها أنت (8 أحرف على الأقل). هذه هي كلمة السر الوحيدة التي تحتاجها.
- يُنشأ الملف `private.enc.pem` مشفراً بكلمة السر، ويُحدَّث المفتاح العام داخل `src/lib/license/public-key.ts`.
- بعد ذلك أعد بناء البرنامج: `npm run build` ثم ملفات EXE.

## ثانياً: توليد كود تفعيل لعميل

1. العميل يفتح البرنامج فتظهر شاشة التفعيل وفيها **كود الجهاز** (زر نسخ).
2. يرسل لك كود الجهاز (أو يضغط زر واتساب في الشاشة فيرسل لك الكود مباشرة).
3. تشغّل:

```bash
node license-admin/issue.mjs --name "اسم العميل" --machine XXXX-XXXX-XXXX-XXXX --days 365
```

- `--days 365` سنة. `--days 0` أو بدون المعامل = ترخيص دائم.
- تُطلب كلمة السر، ثم يُطبع كود التفعيل. أرسله للعميل كما هو.
- كل كود يُسجَّل في `issued.log` للرجوع إليه.

## ثالثاً: الفترة التجريبية

- مدتها وأصناف التجربة في `src/lib/license/config.ts` (`TRIAL_DAYS` و `TRIAL_PRODUCT_CODES`).
- تبدأ من أول تشغيل للبرنامج على الجهاز.

## أمان المفتاح الخاص

- انقل `private.enc.pem` إلى مكان آمن (فلاشة مشفرة أو حساب سحابي خاص) ثم **احذفه من المشروع**.
- لا ترفع هذا المجلد على GitHub أو أي مكان عام (الملفات مستبعدة في `.gitignore` لكن احذر).
- إذا فقدت كلمة السر أو الملف، لا يمكنك توليد أكواد جديدة. عندها تحتاج `keygen.mjs --force` وكل الأكواد القديمة تتوقف.
- إذا تسربت كلمة السر أو الملف، أعد إنشاء المفاتيح بـ `--force`، وأعد بناء البرنامج، وأصدر أكواداً جديدة للعملاء.
